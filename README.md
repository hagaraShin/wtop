# wtop - Мониторинг ресурсов на основе WebUI 

## Зависимости

Зависимости:
Node.js v24 LTS или новее(Репозитори Ubuntu 22.04 содержат очень старую версию, используйте nvm для того, чтобы скачать новую)
Остальное можно скачать с помощью:

```
  sudo apt install cmake make gcc g++ git
```

Для того,чтобы скачать репозиторий вместе с WebUI, используйте:

```
  git clone --recurse-submodules https://github.com/hagaraShin/wtop.git
```

## Сборка

```
  cmake -B build
  cd build
  make
```

В папке ./build/bin будет исполняемый файл wtop

## Установка

Установка может быть произведена с помощью:
```
  sudo make install
```

Приложение появится в меню приложений(может понадобиться время), а также wtop будет коммандой терминала
